# Ireland-YouTube-Engagement-Analysis
An exploratory analysis of YouTube search trends in Ireland using 
Google Trends data — identifying seasonal engagement patterns, 
top queries and rising search topics for 2025–2026.

# Ireland YouTube Engagement Analysis

An end-to-end data analysis project using real Google Trends data 
to uncover YouTube engagement patterns in Ireland. Built using 
Python (pandas, matplotlib, seaborn) in Google Colab.

## Key Findings
- YouTube interest peaked at 90.8 in Q4 2025 and dropped to 84.2 in Q1 2026
- Movies and free content dominate Irish YouTube searches
- Seasonal dip identified around Christmas/New Year period

## Tools Used
- Python (pandas, matplotlib, seaborn)
- Google Trends
- Google Colab
